# Usha Makeup and Nails

Public portfolio site for the New Baneshwor studio.

## Local setup

```bash
npm ci
npm run dev
```

## Shared Node.js hosting

1. Pull the repo on the server
2. Set **Application startup file** to `server.js`
3. Use Node.js 20 or newer
4. Install, build, and start:

```bash
npm ci
npm run build
npm start
```
